=====================
Product Tag Pricelist
=====================

This module allows to use product tags to set pricelists.
IMPORTANT: The pricelist is applied even if just one tag applied to the product matches one tag set in the pricelist.


Installation
============

To install this module, you need to:

#. Just install.


Configuration
=============

To configure this module, you need to:

#. Go to a pricelist.
#. Select or create a pricelist line.
#. Select 'Product Tags' as the 'Apply On' option and select the product tags.

=====

To use this module, you need to:
