This module adds a field in the product.template with the country. The
country will be shown at the end of the product display_name.

.. contents::
   :local:

Configuration
=============

To configure this module, you need to:

1. Go to inventory module -> Products -> Products
2. Create or edit a new product
3. Add a country in the country field

Usage
=====

To use this module, you need to:

1. Go to Sales, Inventory or Invoices Module.
2. Create a new one.
3. Add a new line with a product with country

You will see the country name on the end of the product name.
