If you want to modify or enter the old id of a product template:

1. Go to Products.
2. Select or create a new product.
3. Go to 'Migration Info' tab.
4. Enter/Edit the fields.

If you want to modify or enter the old id of a product:

1. Go to Products Variants.
2. Select or create a new product.
3. Go to 'Migration Info' tab.
4. Enter/Edit the fields.

If you want to modify or enter the old id of a category:

1. Go to Inventory -> Configuration -> Product Categories.
2. Select or create a new category.
3. Go to 'Migration Info' tab.
4. Enter/Edit the fields.
